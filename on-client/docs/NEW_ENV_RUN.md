## 재현 절차 메모

1. `on-client/`를 새 빈 폴더로 복사(실행 파일만, 외부 서비스 설정 없음).
2. `npm run check` → 통과. `ON_PORT=5299 npm run demo` → `http://127.0.0.1:5299` 응답, `/`·`/app.js`·`/student/extension.mjs` 200, `/api/*` 예제 자료 응답.
3. `ON_PORT=5298 npm start` → 연결 확인 모드로 부팅, 원천 없이 `ENGINE_NOT_CONNECTED` 응답(연결 없음이 정상 표시됨).
4. 거부 확인: 쿼리 문자열 요청은 `QUERY_REJECTED`, 다른 출처의 POST는 `ORIGIN_REJECTED`로 닫힘.
5. 끄고 다시 켠 뒤 같은 동작을 확인했습니다(별도 포트 재실행).
