# 돈 들이지 않고 끝까지 하는 방법

3~6차의 모든 필수 과제와 심화 과제는 결제 없이 할 수 있습니다. 유료 가입, 카드 등록, API 키 충전, 유료 호스팅, 도메인·장비 구매를 요구하지 않습니다. 유료 도구 사용이나 결제로 추가 점수를 주지 않습니다. 무료 한도에 걸리면 아래 로컬 경로로 진행합니다.

## 1. 기본 경로: 지금 쓰는 무료 프로젝트를 그대로 씁니다

- 3차까지 쓰던 Vercel 과 Supabase 프로젝트를 그대로 이어 씁니다. 새 프로젝트를 만들 필요가 없습니다.
- **자기 Supabase 프로젝트의 서버 SQL 실행 환경에서만** 키트의 `supabase/product_kv.sql` → `supabase/product_operator.sql` 순서로 초기화합니다. 중앙 ALEPH DB에서 실행하지 마세요.
- operator 템플릿에는 이메일 확인이 끝난 **본인 계정 UUID**와 서버의 `PRODUCT_PROJECT_ID`와 정확히 같은 프로젝트 ID를 넣습니다. 기존 로그인 계정의 역할이 새 제품 저장소에 자동으로 복사되지는 않습니다. 초기화 뒤 로그인하고 `/api/product/v1/me`에서 operator 역할을 확인하세요.
- Vercel 프로젝트의 서버 환경변수에 `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `PRODUCT_PROJECT_ID` 를 넣습니다. 서비스 키는 서버 환경변수에만 둡니다. 브라우저 코드, 저장소, 화면, 채팅에 붙여 넣지 마세요.

## 2. 이런 일이 생기면 대체 경로로 갑니다

| 상황 | 이렇게 하세요 |
|---|---|
| Supabase 프로젝트가 일시중지됐다 | 무료 프로젝트는 한동안 쓰지 않으면 일시중지될 수 있습니다. Supabase 대시보드에서 프로젝트를 다시 시작하면 됩니다(결제 필요 없음). 다시 시작이 안 되면 대체 경로로 갑니다. |
| 무료 프로젝트 개수가 꽉 찼다 | 새 프로젝트를 만들지 않습니다. 지금 쓰는 프로젝트에 표만 더하면 됩니다. 기존 프로젝트나 자료를 지우라는 요구는 없습니다. |
| Vercel 사용량 한도에 걸렸다 | 대체 경로로 내 PC 에서 돌립니다. |
| 계정에 문제가 생겼다 | 강사에게 알리고 대체 경로로 진행합니다. 계정을 새로 여러 개 만들어 한도를 피하지 마세요. |

일시중지나 한도, 제공자 시험 환경 미준비 때문에 확인하지 못한 항목은 "미검증"으로 따로 표시하고, 여러분의 실패로 세지 않습니다. 다만 프로젝트를 다시 시작하거나 로컬 경로로 옮기는 일은 여러분이 해야 합니다. 개인 프로젝트 초기화가 운영 심판·집행 제공자·중앙 DB 연결을 보증하지는 않습니다.

## 3. 대체 경로: 내 PC 에서 돌립니다

```sh
node scripts/test-identities.mjs --local    # 연습용 계정 A·B·OP
npm run start:local                         # 계정 생성 뒤 http://127.0.0.1:8787
```

- 자료는 `.data/product.json` 에 저장되고, 서버를 껐다 켜도 남습니다.
- 서버는 시작할 때 계정 파일을 읽습니다. 계정을 다시 생성하거나 지울 때는 서버를 먼저 중지하고, 필요한 명령 하나를 실행한 뒤 서버를 다시 시작하세요. 재생성하면 계정 ID·비밀번호가 바뀌므로 기존 로그인과 해당 계정이 소유한 연습 자료를 그대로 사용할 수 없습니다.

```sh
node scripts/test-identities.mjs --local          # 재생성할 때
node scripts/test-identities.mjs --local --remove # 지울 때
```

- `.data/` 폴더는 저장소에 올리지 않습니다(.gitignore 에 있음).
- 판정 기준은 기본 경로와 같습니다. 화면만 보여 주는 것이 아니라 실제 서버가 요청을 받고 저장해야 합니다.
- 공개 시험은 `npm test`로 실행합니다. 22개 가운데 미구현 업무 기능을 검사하는 시험이 실패하는 것은 정상입니다. 제공 코드의 인증·상태 조회와 학생이 구현할 업무 기능은 구분해 확인하세요.

공식 시험 신원의 `node scripts/test-identities.mjs --supabase --register`는 현재 구현 미완료입니다. `ALEPH_IDENTITY_REGISTER_URL`이 있어도 계정을 생성하지 않고 종료 코드 2로 끝납니다. 우선 위 로컬 연습을 사용하세요.

3차 10/13~16에는 기존 6~12단계와 XDR 6개가 필수입니다. 4~6차 제품 평가는 D1~D4 60점, 통합·변경 합산 15점, v0.9 릴리스 10점, 수복 15점으로 총 100점이며 기존 19개 평가와 별개입니다. [학생 안내서](./STUDENT_GUIDE.md)의 일정에 따라 자료는 미리 보고 개발할 수 있지만, 실제 차수 개시·제출은 서버가 확인한 기간·개방 상태·권한을 따라야 합니다.

## 4. AI 와 외부 정보

- 개인 AI API 키를 사거나 충전하지 않습니다. 제품의 "설명" 기능은 실제 판정 근거(어느 정책 몇 판의 어느 규칙)를 보여 주는 것으로 충분합니다.
- 침해 정보 대조는 제공한 학습 자료나 공개 자료로 합니다. 유료 위협 정보 서비스에 가입하지 않습니다.
- 교육기관이 무료로 제공하는 AI 연결이 있으면 선택해서 쓸 수 있습니다. 쓰지 않아도 점수에 불이익이 없습니다. 흉내 낸 응답을 실제 AI 호출이라고 표시하면 안 됩니다.
